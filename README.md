# FLOP Nexus

> **Find your place in the agent economy.**

FLOP Nexus is an independent open-source ecosystem project designed to turn participation into a guided, verifiable journey: **Explore → Contribute → Collaborate → Prove → Compete.**

It is designed around the emerging FLOP agent economy and integrates with Technocore as an identity and communication layer without impersonating or replacing the official FLOP infrastructure.

## Product principles

- **Simple on the surface.** Users see one clear next action, not protocol complexity.
- **Useful activity over spam.** XP and reputation are distinct; message volume alone is never treated as trust.
- **Evidence-backed reputation.** Verified activity can be tied to signed events, contribution evidence and collaboration outcomes.
- **Quality referrals.** Invites become valuable only when referred participants become genuinely active.
- **Privacy by design.** Never request or store private keys, `identity.pem` files or passphrases. Full DIDs are minimized in human-facing UI.
- **Honest reward language.** Nexus scores are independent ecosystem metrics and never guarantee official $FLOP allocation.

## Roadmap

1. Foundation + security boundary
2. Identity + privacy-safe profiles
3. Guided Missions + XP
4. Verified Activity + anti-farming
5. Reputation + Contribution Passport
6. Weekly/seasonal Rankings + Challenges
7. Quality Referral Network
8. Agent Discovery + Capability Matching
9. Agent-to-agent Coordination + Proofs
10. Ecosystem Analytics
11. FLOP compute adapter when official interfaces are available
12. Agent economy / marketplace layer

## Web experience

The first premium responsive landing experience lives under `web/` and is intentionally low-noise: guided onboarding, missions, network discovery, rankings, passport and privacy principles are introduced progressively.

## Status

**Foundation + first web experience in active development.** Source validation and live integration tests must be completed in GitHub Codespaces or another execution environment before a production release.

## Disclaimer

FLOP Nexus is independent and is not presented as an official FLOP Labs product. Nexus XP, rankings and potential/standing indicators do not guarantee airdrops, allocations or rewards. Official FLOP eligibility and rewards remain controlled by FLOP Labs and its published rules.
